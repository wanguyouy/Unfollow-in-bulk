Telegram 本地缓存恢复

离线 · 私密频道也能取
不联网。直接解本机 Telegram Desktop 落盘的缓存 —— 网页预览被关掉的频道/群，只要在本机看过，磁盘上就有。
默认导出到「桌面\Telegram本地缓存」
进度
能取到什么 / 取不到什么
能取到：图片（jpg/png/webp/gif）、圆视频（webm）、语音，都是从本机缓存解密出来的完整原文件。
视频只能拿到一部分：视频按 8MB 分片存，文件名是缓存键的哈希、不含偏移，所以分片没法排序拼回整段；只有「索引在文件头」的那种能直接播，其余标注缺索引。
应用锁：开了口令锁的 Telegram，本地密钥被口令包着，解不开 —— 先在设置里临时关掉应用锁再扫。
隐私：全程只读本机文件、不联网、不上传；导出目录里的 index.html 可以直接在浏览器里翻看，manifest.json 是同一份清单。

微信视频号下载

实验 · 直存原始流
退出微信 → 清缓存 → 启动捕获 → 播放视频 → 导出。
为什么要清缓存 / 关于证书
清缓存：视频号页面的 HTML / JS 若命中微信 WebView 磁盘缓存，浏览器不发请求，代理就注入不了、拿不到 decodeKey。清理只做可恢复的目录重命名，不删任何文件。
怎样算拿到 key：日志出现 [WorkerKey] 或 [CacheDbKey]。每个视频的 key 独立，不会串用。
证书：安装后本机信任一个本地根证书（仅当前用户），不用时点「卸载证书」移除。
